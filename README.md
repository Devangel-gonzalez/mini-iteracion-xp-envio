## Preguntas de reflexion

# 1. ¿Qué ventaja tuvo escribir primero los casos de prueba?

Nos obligó a pensar claramente en el comportamiento esperado antes de empezar a programar.

# 2. ¿Qué aportó trabajar en pareja?

El Pair Programming ayuda a detectar errores mas rapido y discutir desiciones.

# 3. ¿Fue fácil incorporar el nuevo requerimiento?

Sí. Gracias a que las pruebas ya existian y el método era pequeño, agregar el soporte para clientes Premium fue facil.

# 4. ¿Qué práctica de XP facilitó más el cambio?

TDD fue la práctica que más facilitó el cambio. Al tener una suite de pruebas completa, pude modificar el código con confianza.
